CORITIBA — ALTO DA GLÓRIA
Projeto conceitual em HTML, CSS e JavaScript puro.

ESTRUTURA
- index.html: estrutura do site
- css/style.css: todo o visual, responsividade e animações
- js/script.js: carrossel do elenco, filtros, menu e microinterações
- assets/images/: jogadores, escudo e produtos

COMO ABRIR
Extraia a pasta e abra o arquivo index.html no navegador.

OBSERVAÇÃO
Projeto visual independente e não oficial, criado como conceito de interface.
